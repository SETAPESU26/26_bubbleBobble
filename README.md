# Bubble Bobble Repair Lab

Run `python game.py`. Arrow keys move, Up jumps, and Space blows a bubble.

Repair targets:
- Give bubbles horizontal travel before switching to upward buoyancy.
- Trap an enemy on collision and anchor it inside the bubble.
- Pop trapped bubbles from above and award a combo item.

Check that bubbles leave the screen, trapped enemies cannot move independently, and a popped enemy is counted once.
